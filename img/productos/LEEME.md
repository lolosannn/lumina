# Fotos de productos

Subí acá las fotos de los productos. Cada foto tiene que tener **exactamente** el nombre de la lista (en minúsculas, sin espacios ni tildes):

| Producto                    | Nombre del archivo          |
|-----------------------------|-----------------------------|
| Budín de limón              | `budin-limon.jpg`           |
| Budín de limón glaseado     | `budin-limon-glaseado.jpg`  |
| Budín de vainilla con chips | `budin-vainilla-chips.jpg`  |
| Budín de chocolate          | `budin-chocolate.jpg`       |
| Budín marmolado             | `budin-marmolado.jpg`       |
| Budín integral              | `budin-integral.jpg`        |
| Cookies clásicas            | `cookies-clasicas.jpg`      |
| Torta matera                | `torta-matera.jpg`          |

- Mientras una foto no esté, la web muestra "Foto próximamente" en su lugar.
- Las fotos se ven recortadas en formato horizontal (4:3), así que conviene que el producto esté centrado.
- Ideal: unos 1200 px de ancho y menos de 500 KB cada una, para que la página cargue rápido.
- Si las subís con otro nombre o formato (por ejemplo `.png` o `IMG_1234.jpg`), avisá y se renombran o se cambia el nombre en `js/productos.js`.

Configurar el administrador

Esto se hace una sola vez por dispositivo (celular, compu). Necesitás una llave de GitHub para que la página pueda guardar los cambios, y una contraseña que vos elijas para entrar.

¿Cómo consigo la llave de GitHub?
  1. Entrá a github.com/settings/personal-access-tokens/new con la cuenta dueña de la web.
  2. Token name: Admin Lúmina. Expiration: la fecha más lejana que te deje.
  3. Repository access: “Only select repositories” y elegí lumina.
  4. Permissions → Repository permissions → Contents: “Read and write”.
  5. No elijas el tipo “classic”: tiene que ser una llave fine-grained, que solo puede tocar este repositorio.
  6. Tocá Generate token y copiá el código (empieza con github_pat_).
